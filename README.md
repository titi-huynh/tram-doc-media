# tram-doc-media

Kho chứa file nhạc nền cổ điển cho **Trạm Đọc** (https://tram-doc-sand.vercel.app) — tính năng "Đĩa nhạc".

Mọi file trong các release của repo này đều là bản thu thuộc **phạm vi công cộng (Public Domain)** hoặc **Creative Commons** tự do (CC0 / CC BY / CC BY-SA), lấy từ Wikimedia Commons / Musopen. Tác phẩm, nghệ sĩ trình diễn, giấy phép và trang nguồn của từng bài được ghi ngay trong giao diện Đĩa nhạc của Trạm Đọc và trong ghi chú của từng release.

Các file đã được chuyển mã sang MP3 160 kbps và cân bằng âm lượng (loudnorm −16 LUFS) để nghe nền khi đọc sách.
